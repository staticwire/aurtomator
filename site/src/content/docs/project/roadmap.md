title: Roadmap
---

This page lists what aurtomator intends to do and not to do until the end of 2027. Plans can change, and this page changes with them.

## Planned

- Follow the changes of the AUR, makepkg and GitHub Actions, so that updates keep working.
- Add strategies for new kinds of upstreams on request, through the [strategy request form](https://github.com/staticwire/aurtomator/issues/new?template=strategy_request.yml).
- Review the scripts and workflows for security weaknesses before releases, and keep the [security model](/project/security-model/) current.
- After the first stable release: optional jobs that test the build of updated packages, for repositories with enough GitHub Actions minutes or with runners of their own.

## Not planned

- Package repositories other than the AUR.
